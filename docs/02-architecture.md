# Архитектура

## Стек

- Java 21, Spring Boot 4.1 без веб-сервера (`spring.main.web-application-type=none`), сборка Gradle (`./gradlew`).
- Telegram Bot API без библиотек: `java.net.http.HttpClient`, long polling `getUpdates`.
- Модели — OpenAI-совместимый Chat Completions по HTTP (OpenRouter, Groq, Google Gemini), без SDK.
- Хранилище — H2 в файле. Всё состояние — **один JSON** в таблице `mentor_state` (строка `id = 1`),
  сериализация Jackson 3 (`tools.jackson`).
- Один процесс, один экземпляр на токен. Два экземпляра с одним токеном будут красть друг у друга сообщения.

## Три цикла

`@Scheduled` в `MentorBot`, пул планировщика — 3 потока (`spring.task.scheduling.pool.size=3`):

| Метод | Период | Что делает |
|---|---|---|
| `poll()` | 1 с | Забирает обновления Telegram, **сначала** сохраняет `updateOffset`, потом обрабатывает (не более одного раза) |
| `reminders()` | 8 с | `Planner.evaluate` → напоминание урока → очередь вердиктов → «Начинаю»/«Через час» → вопрос дня → пинок Школы 21 → недельный отчёт |
| `review()` | 5 с | Проверяет отложенные сдачи (`lesson.pending`), если проверка не успела сразу |

## Классы

| Класс | За что отвечает |
|---|---|
| `MentorApplication` | Точка входа Spring, включает планировщик |
| `MentorBot` | Оркестрация: входящие сообщения, команды, разговор, сдачи и вердикты, напоминания, школьный режим, вопрос дня, разминка |
| `MentorModel` | Все обращения к моделям: классификатор, проверки, разговор, пересказ вердикта, подсказка, git, карьера, распознавание голоса. Цепочки моделей, повторы, чистка текста |
| `MentorContext` | «Заметки» Олега: снимок состояния (время, дедлайн, стрик, текущий шаг, неделя, задачи, навыки, проекты), который идёт в системный промпт разговора. Плюс быстрый ответ на «урок #N зачтён?» |
| `Planner` | Календарь: уроки на 7 дней вперёд, граница дня 04:00, хвосты (`todayFirst`, `tail`), оценка прошедших дней, строгие часы, напоминания (`Notice`), стрик, пропуск, пауза |
| `LearningCatalog` | Учебное содержание: темы, карточки, формулировки заданий и критерии, вопросы собеса, каталог LeetCode, шаги T04B, практика дня |
| `StudyMaterials` | Ссылки для чтения по темам: что изучить, где остановиться, сколько минут |
| `MentorTone` | Готовые тексты (напоминания, пропуски, старт, недельный отчёт) и `MODEL_STYLE` для проверок |
| `DayMemory` | Переписка учебного дня: что видит Олег (до 20 000 символов), последняя реплика ментора, прошлые попытки за день |
| `SchoolMentor` | Школа 21: план шагов T04B к дедлайну, темп, статус, вечерний пинок, заметки школьного режима |
| `ProjectCheckins` | Разбор отчёта о ходе Java-проекта (`/progress`). Случайные проверки в коде есть, но **сейчас не вызываются** (`maybeSendProjectPing` нигде не зовётся) |
| `TelegramApi` | Bot API: getUpdates, sendMessage (обычный и с форматированием), кнопки, меню, force reply, документы, голосовые, «печатает…» |
| `TelegramText` | Перевод разметки модели (```код```, `код`, **жирный**, `# заголовок`) в entities Telegram |
| `StateStore` | Чтение/запись JSON-состояния. `read`/`write` синхронизированы: запись = загрузить → изменить в лямбде → сохранить, если изменилось |
| `MentorState` | Модель данных (см. ниже) |
| `LocalProjectGit` | Метаданные git локальной копии T04B для кнопки «Проверить Git» |

## Путь сообщения

```
Telegram ──getUpdates──▶ poll()
                         │  1. updateOffset = id + 1  (сохранено ДО ответа — at most once)
                         ▼
                       handle(update)
                         │  голосовое → transcribe (Groq Whisper) → «Распознано: …»
                         │  кнопки меню / «ответ на сообщение бота» / «Вот моё решение:» → команды
                         ├── /команда ──▶ respond() ──▶ ответ (+ /submit → reviewNow)
                         ├── идёт мини-собес ──▶ interviewAnswer()
                         ├── школьный режим ──▶ schoolTalk()
                         └── обычный текст ──▶ talk()
talk():
  a) «урок #N зачтён?» → готовый ответ из базы (progressReply), без модели
  b) «решил / accepted / задача 146» → solvedWarmup → отметить задачу решённой
  c) открыт шаг урока или вопрос дня → классификатор (route):
       ANSWER → queueSubmission → reviewNow (вердикт через секунды)
       RECALL → recallAnswer (проверка вопроса дня)
       QUESTION / CHAT → в разговор
  d) разговор: CHAT_RULES + справка режима + заметки (MentorContext) + переписка дня (DayMemory)
     → ответ модели → withoutChatCredit (вырезает «засчитано», карточки урока и т. п.) → Telegram
```

### Проверка сдачи

```
reviewPending():
  model.reviewLesson()        ← строгая проверка (LLM_REVIEW_MODELS; для «Алгоритмы»/«Практика» первым gpt-oss)
     → по шагам: accepted / revise / missing + разбор + номер строки-доказательства
  voiced()                    ← Олег пересказывает разбор своим голосом (voice), вердикт не трогает
  store.write:
     accepted → accept(): position++, accepted++, stepsByDay[день]++, навык
     revise   → «Нужна доработка», навык с пробелом
     missing  → «Пока нет ответа на шаг N» (или тихо — если это была болтовня, quietMissing)
  → feedbackQueue → flushFeedback() отправляет
```

Зачёт пишет **только приложение** по JSON проверки. Разговорная модель не может ничего засчитать.

## Состояние (`MentorState`)

Один JSON. Главное:

| Поле | Смысл |
|---|---|
| `zone`, `flexible` | Часовой пояс (`Europe/Moscow`), свободный режим |
| `lessons[]` | Уроки: `id`, `start`, `flexibleEnd` (дедлайн), `tasks[]` (4 шага), `position` (текущий шаг), `accepted`, `pending` (сдача на проверке), `carried` (необязательный хвост прошлого дня), `strict`, `paused`, `windowClosed`, служебные флаги напоминаний |
| `conversation[]` | Переписка (вопрос, ответ, время, номер урока для сдач). Хранится текущий и прошлый учебный день |
| `stepsByDay` | Зачтённые шаги по учебным дням — основа стрика |
| `evaluatedDays`, `strictRemaining`, `skippedDays`, `pausedThrough` | Итог прошедших дней, сколько строгих уроков впереди, пропуски, пауза |
| `recallDay/Topic/MessageId/Answered/Attempt` | Вопрос дня |
| `commitAt/LessonId/Accepted`, `snoozeUntil` | «Начинаю» и «Через час» |
| `lastReminderAt`, `lastUserMessageAt` | Игнорирует ли он напоминания (тон жёстче) |
| `schoolMode`, `schoolModeDay`, `schoolPlanStart*`, `schoolNudgeDay`, `schoolStepDay` | Школьный режим |
| `projects[]` | Проекты (T04B), `completedSteps`, дедлайн |
| `solved`, `lastOfferedProblem` | Решённые задачи LeetCode, последняя предложенная разминка |
| `skills` | Навыки по темам: подтверждён/пробел, дата повтора |
| `feedbackQueue` | Вердикты, ждущие отправки |
| `updateOffset`, `ownerChat`, `pendingCommandReply` | Служебное Telegram |
| `curriculumVersion` | Версия миграции учебного плана (сейчас 4) |

**Совместимость:** база живёт между версиями. Новое поле — только со значением по умолчанию. Переименовать
или удалить поле = потерять данные в проде. Нужна миграция — делай её в `Planner.evaluate` /
`updateCurriculum` и проверяй на копии прод-базы (`ProductionCopyDryRunTest`).

## Время

- Часовой пояс состояния — `Europe/Moscow`.
- В свободном режиме учебный день — **04:00 → 04:00** (`Planner.DAY_START`, `Planner.date()`): всё, что
  считает «день» (стрик, переписка, вопрос дня, школьный режим), идёт через `Planner.date()`. Не вызывай
  `toLocalDate()` напрямую, иначе после полуночи появится второй «сегодня».
- Уроки начинаются в 04:00 и кончаются в 04:00 следующего дня. Недоделанный урок остаётся открытым ещё на сутки
  как необязательный хвост.
- **Сегодняшний урок всегда первый.** Где бот выбирает «тот самый» урок — `Planner.active`, `submittingLesson`
  (куда идут ответы), заметки Олега (`MentorContext`), напоминания, — урок текущего учебного дня идёт раньше
  хвоста (`Planner.todayFirst`). Хвост получает ответы, только когда сегодняшний урок закрыт; напоминаний про
  него нет.
- Напоминания и окна (вопрос дня 12:00–21:00, пинок Школы 20:30–22:30, недельный отчёт 10:00–21:00,
  сообщения о пропуске 09:00–22:00) считаются по местному времени, после полуночи не пишут.

## Расписание событий

| Событие | Когда | Где в коде |
|---|---|---|
| Напоминания урока | 10:00, 14:00, 18:00, 20:00, 21:30, 22:30, 23:30 ±30 мин (последнее ≤ 23:45), каждое живёт ≤ 1 ч | `Planner.DAILY_REMINDERS`, `reminderTimes`, `flexibleNotice` |
| «Начинаю» → проверка | через 40 мин | `MentorBot` `/startnow`, `maybeSendNudge` |
| «Через час» | через 1 ч | `/snooze`, `maybeSendNudge` |
| Вопрос дня | случайно 12:00–21:00, не позже 22:00 | `maybeSendRecall` |
| Пинок Школы 21 | 20:30–22:30, раз в день | `SchoolMentor.nudge` |
| Сообщение о пропуске | 09:00–22:00, до 16 ч после конца урока | `Planner.missedNotice` |
| Недельный отчёт | раз в неделю, 10:00–21:00 | `maybeSendWeekly` |
| Строгие окна | 19:00–21:00 (Mentor Focus с 18:45) | `Planner.FOCUS_FROM/TO`, `assignStrict` |
